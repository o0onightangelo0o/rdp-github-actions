# 🖥️ RDP على GitHub Actions — جهاز Windows مجاني عن بُعد

مشروع جاهز يمنحك **جهاز Windows كامل** يعمل على خوادم GitHub، وتتصل به عن بُعد
إما عبر **RDP حقيقي** (تطبيق Remote Desktop Connection) أو عبر **المتصفح**.

> ⚠️ **اقرأ أولاً قسم [الحدود القانونية والاستخدام المسموح](#-الحدود-القانونية-والاستخدام-المسموح)** قبل التشغيل.

---

## 📦 محتويات المشروع

| الملف | الوظيفة |
|---|---|
| `.github/workflows/rdp-ngrok.yml` | **الخيار الرئيسي** — RDP حقيقي عبر نفق ngrok |
| `.github/workflows/desktop-browser.yml` | **الأسهل** — سطح مكتب داخل المتصفح، بلا أي حساب |
| `.github/workflows/rustdesk-no-account.yml` | **تجريبي** — RustDesk بخادم ذاتي، بلا حساب |
| `.github/workflows/rdp-hardened.yml` | نسخة مؤمّنة للاستخدام المتكرر (Secrets + تنبيه تيليجرام + إيقاف عند الخمول) |
| `scripts/enable-rdp.ps1` | تفعيل RDP + NLA + جدار الحماية + المستخدم + Auto-Logon |
| `scripts/disable-rdp.ps1` | إغلاق RDP وتنظيف الجلسة (يشمل حذف بيانات Auto-Logon) |
| `scripts/restart-to-console.ps1` | إعادة تشغيل اختيارية لإنشاء جلسة Console تفاعلية |
| `scripts/make-rdp-file.ps1` | توليد ملف `.rdp` جاهز للنقر المزدوج |
| `docs/` | دليل الإعداد، الأمان، وحل المشكلات |

### أي workflow أختار؟

```
هل تريد أعلى جودة وأداء (RDP حقيقي)؟
  └─ نعم → rdp-ngrok.yml        (يتطلب حساب ngrok مجاني)
  └─ لا أريد التسجيل بأي مكان → desktop-browser.yml  (الأسهل، يعمل دائماً)
  └─ سأستخدمه بشكل متكرر → rdp-hardened.yml         (الأأمن)
  └─ أحب التجريب → rustdesk-no-account.yml
```

## 🚀 البدء خلال 10 دقائق

### 1) أنشئ مستودعاً جديداً على GitHub
- اذهب إلى <https://github.com/new>
- **Repository name:** `rdp-github-actions` (أي اسم تريده)
- اختر **Public** ← ⚠️ مهم! المستودع العام يمنحك **دقائق Actions غير محدودة مجاناً**.
  المستودع الخاص يعطيك 2000 دقيقة/شهر فقط (وساعات Windows تُحسب ×2).
- اضغط **Create repository**

### 2) ارفع ملفات المشروع
**الطريقة الأسهل (من المتصفح):**
1. داخل المستودع اضغط **Add file → Upload files**
2. اسحب مجلد `.github` ومجلد `scripts` ومجلد `docs` (حافظ على هيكل المجلدات!)
3. اضغط **Commit changes**

**أو عبر Git من جهازك:**
```bash
cd rdp-github-actions
git init
git add .
git commit -m "إضافة بيئة RDP عبر GitHub Actions"
git branch -M main
git remote add origin https://github.com/اسمك/rdp-github-actions.git
git push -u origin main
```

### 3) احصل على ngrok Authtoken (مجاني، دقيقتان)
1. سجّل في <https://dashboard.ngrok.com/signup> (يمكن التسجيل بحساب GitHub نفسه)
2. من لوحة التحكم انسخ الـ **Authtoken**
3. في مستودعك: **Settings → Secrets and variables → Actions → New repository secret**
4. الاسم: `NGROK_AUTHTOKEN` — القيمة: التوكن المنسوخ → **Add secret**

> 💡 الخطة المجانية في ngrok تكفي تماماً: نفق TCP واحد، وعنوان يتغير كل تشغيل.

### 4) شغّل الجلسة
1. في مستودعك اذهب إلى تبويب **Actions**
2. قد تظهر رسالة "Workflows aren't being run" → اضغط **I understand my workflows, go ahead and run them**
3. من القائمة الجانبية اختر **RDP - Windows + ngrok**
4. اضغط **Run workflow**
5. اضبط الخيارات:

   | الخيار | ماذا يعني | القيمة المقترحة |
   |---|---|---|
   | `session_minutes` | مدة بقاء الجهاز حياً | `60` للتجربة الأولى |
   | `rdp_user` | اسم المستخدم | اتركه `ghadmin` |
   | `rdp_port` | المنفذ الداخلي | اتركه `3389` |
   | `show_password_in_summary` | إظهار كلمة المرور في الملخص | `true` (وإلا لن تراها!) |
   | `restart_machine` | إعادة تشغيل لإنشاء جلسة Console | `false` — فعّلها فقط عند الشاشة السوداء |

6. اضغط **Run workflow**

### 5) اتصل بالجهاز
1. اضغط على الـ Run الذي بدأ (سيظهر بدائرة صفراء)
2. انتظر ~2-3 دقائق حتى تنتهي خطوة **Show RDP connection info**
3. في صفحة الـ Run ستجد صندوق **Summary** يحتوي على:
   ```
   Host : 0.tcp.ngrok.io
   Port : 12345
   User : ghadmin
   Pass : Xk9mP2vL
   ```
4. على جهازك: `Win + R` → اكتب `mstsc` → Enter
5. في حقل **Computer** اكتب: `0.tcp.ngrok.io:12345`
6. أدخل اسم المستخدم وكلمة المرور ← **ستكون داخل Windows!** 🎉

## 🌐 الخيار الأبسط: سطح مكتب في المتصفح (بدون تسجيل في أي مكان)

إذا كنت لا تريد إنشاء حساب ngrok:

1. في تبويب **Actions** اختر **Windows Desktop in Browser (بدون حساب)**
2. اضغط **Run workflow** (كلمة المرور تُولّد تلقائياً)
3. من صندوق **Summary** انسخ رابط `https://xxxx.trycloudflare.com`
4. افتحه في متصفحك وأدخل كلمة المرور ← سطح مكتب Windows يظهر مباشرة

**مقارنة سريعة بين الخيارات الثلاثة:**

| | ngrok + RDP | VNC في المتصفح | RustDesk |
|---|---|---|---|
| يحتاج حساب | نعم (مجاني) | ❌ لا | ❌ لا |
| جودة الصورة | ⭐⭐⭐⭐⭐ ممتازة | ⭐⭐⭐ متوسطة | ⭐⭐⭐⭐ جيدة |
| سرعة الاستجابة | عالية | متوسطة | جيدة |
| الصوت | ✅ مدعوم | ❌ لا | ✅ مدعوم |
| نقل الملفات | ✅ كامل | محدود | ✅ |
| يعمل من الهاتف | ✅ تطبيق RD Client | ✅ متصفح | ✅ تطبيق RustDesk |
| موثوقية التشغيل | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ | ⭐⭐ (تجريبي) |
| يحتاج تثبيت عميل | mstsc (موجود) | ❌ لا | نعم |

## ⚖️ الحدود القانونية والاستخدام المسموح

هذه النقطة **مهمة جداً** — خدمات GitHub Actions مُرخّصة في
[شروط استخدام GitHub](https://docs.github.com/en/site-policy/github-terms/github-terms-for-additional-products-and-features)
لأغراض **CI/CD وتطوير واختبار البرمجيات**.

### ✅ استخدامات آمنة ومقبولة
- اختبار برنامجك على Windows نظيف
- تشغيل أدوات بناء (compilers) تحتاج Windows
- تجربة إعدادات PowerShell / .NET / Visual Studio
- جلسة تطوير مؤقتة لعدة ساعات

### ❌ استخدامات قد تؤدي لإيقاف حسابك
- **تعدين العملات الرقمية** ← إيقاف فوري ودائم
- استخدامه كخادم دائم 24/7 (تشغيل متكرر بلا توقف)
- استضافة مواقع أو ملفات أو بوتات
- تشغيل ألعاب بشكل دائم أو بثّ
- إخفاء هويتك أو التحايل على حظر خدمات أخرى
- أي نشاط غير قانوني

**النصيحة العملية:** استخدمه عند الحاجة ولفترات معقولة، وأبقِ المستودع
بمحتوى تقني حقيقي (سكربتات، توثيق) — لا مستودعاً فارغاً غرضه الوحيد الـ runner.
وإن كنت تحتاج جهاز Windows دائماً، فاستئجار VPS رخيص (~5$/شهر) أأمن لك بكثير.

## 🔒 الأمان — 5 قواعد لا تتجاهلها

1. **لا تكتب كلمات المرور داخل ملفات الـ workflow** — استخدم Secrets دائماً.
2. **لا تشارك رابط النفق** — من يملك الرابط + كلمة المرور يملك الجهاز.
3. **استخدم النسخة المؤمّنة** (`rdp-hardened.yml`) إذا كنت ستكرر الاستخدام.
4. **تأكد أن خطوة Cleanup تنجح** — تعطيل RDP عند النهاية.
5. **لا تدخل بيانات بنكية أو حسابات حساسة** داخل الجهاز — الجلسة غير مشفّرة بالكامل من طرف GitHub.

التفاصيل الكاملة في: [`docs/SECURITY.md`](docs/SECURITY.md)

## 🔐 النسخة المؤمّنة (للاستخدام المتكرر)

استخدم `rdp-hardened.yml` إن كنت ستشغّل جلسات كثيراً. الفرق:

| الميزة | النسخة البسيطة | النسخة المؤمّنة |
|---|---|---|
| كلمة المرور | تُولّد عشوائياً وتظهر في الملخص | في Secret — لا تظهر أبداً |
| اسم المستخدم | `ghadmin` ثابت | من Secret |
| استقبال البيانات | صفحة الـ Run | **رسالة تيليجرام خاصة** |
| إيقاف عند الخمول | ❌ | ✅ (يوفّر الدقائق) |
| إلغاء الجلسات المتضاربة | ❌ | ✅ `cancel-in-progress: true` |

### الأسرار المطلوبة
| اسم الـ Secret | القيمة |
|---|---|
| `NGROK_AUTHTOKEN` | توكن ngrok |
| `RDP_USERNAME` | اسم مستخدم تختاره |
| `RDP_PASSWORD` | كلمة مرور قوية (16+ حرفاً) |
| `TELEGRAM_BOT_TOKEN` | اختياري |
| `TELEGRAM_CHAT_ID` | اختياري |

### إعداد تنبيهات تيليجرام (3 دقائق)
1. في تيليجرام ابحث عن **@BotFather** ← `/newbot` ← اختر اسماً ← انسخ التوكن
2. ابحث عن **@userinfobot** ← سيرسل لك رقم الـ `Chat ID` الخاص بك
3. أضف الاثنين كـ Secrets: `TELEGRAM_BOT_TOKEN` و `TELEGRAM_CHAT_ID`
4. الآن ستصلك بيانات الاتصال كرسالة خاصة فور جاهزية الجلسة 🔔

> 💡 بديل: استخدم Slack أو Discord Webhook — عدّل خطوة `Notify connection details`.

## 🩺 حل المشكلات

| المشكلة | الحل |
|---|---|
| لا يظهر تبويب Actions | المستودع فارغ — ارفع الملفات أولاً |
| "Workflows aren't being run" | اضغط الزر الأخضر داخل التبويب |
| `Resource not accessible by integration` | Settings → Actions → General → Workflow permissions → **Read and write** |
| فشل خطوة ngrok | تأكد من صحة `NGROK_AUTHTOKEN` وأن حسابك مفعّل بالبريد |
| mstsc يرفض الاتصال | تأكد من كتابة المنفذ بعد النقطتين `host:port` بدون مسافة |
| **شاشة سوداء بعد الدخول** | انتظر 20 ثانية → `Ctrl+Alt+End` → إن استمرت استخدم **desktop-browser** |
| انقطع الاتصال فجأة | الـ Run انتهى أو ngrok أعاد التشغيل → شغّل workflow جديد |
| لا أرى كلمة المرور | فعّل `show_password_in_summary = true` عند التشغيل |
| `The job has exceeded the maximum job execution time` | وصلت حد الـ 6 ساعات — شغّل جلسة جديدة |

القائمة الكاملة: [`docs/TROUBLESHOOTING.md`](docs/TROUBLESHOOTING.md)
